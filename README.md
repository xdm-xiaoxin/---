# 学习通刷课工具-xiaoxin_demo

一个跑在油猴（Tampermonkey）里的超星学习通自动化用户脚本。**答案由你自己的 DeepSeek API 生成**，不依赖任何第三方付费题库。

作业和章节测验默认**不会自动提交**，填完答案停下来等你核对、手动提交。

> 本仓库仅供学习和研究使用，请在使用前阅读 [使用前必读.txt](使用前必读.txt)。使用后 24 小时内删除。

---

## 功能

- **章节学习页** —— 自动播放视频（静音、被暂停会自动恢复）、翻完 PPT/文档/电子书，本页任务点全部完成后自动进下一章
- **作业 / 章节测验** —— 解析题目 → 调 DeepSeek 生成答案 → 自动填入；答案同时显示在页面底部，可逐题核对或点「填入此题」重填
- **考试页** —— 填入答案并按设置自动切换到下一题
- **随时暂停** —— 面板标题栏 ⏸ 一键停掉所有自动化；自动提交倒计时期间也可以终止
- **自动提交（危险）** —— 默认关闭，开启需二次确认，提交前有 60 秒倒计时可反悔

## 快速开始

### 方式一：手动安装（任意系统，推荐）

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（油猴）扩展
2. 打开油猴的「添加新脚本」，把编辑器内容全选删除
3. 用文本编辑器打开 [`配置文件夹/xxt-xiaoxin_demo.js`](配置文件夹/xxt-xiaoxin_demo.js)，全选复制，粘贴进去，`Ctrl+S` 保存
4. 打开学习通课程页面，右下角会出现面板

### 方式二：一键配置（仅 macOS / Windows）

项目根目录里的 `一键配置.command`（Mac）或 `一键配置.bat`（Windows）会自动完成上面这些事：

1. 解包 `配置文件夹/tampermonkey_stable.crx`，装进一个**专用浏览器配置**（不碰你平时的浏览器）
2. 在 `127.0.0.1` 上临时起一个安装页，把脚本喂给油猴
3. 带着扩展参数启动浏览器并打开安装页

```
Mac      双击 一键配置.command
Windows  双击 一键配置.bat
```

首次需要你点几下（这几步没法自动化）：

1. 安装页里点【安装】
2. 油猴若提示需要「允许运行用户脚本」或开发者模式，按提示打开
3. 到面板「API配置」里填 Key（见下）

之后再用直接双击同一个文件即可，油猴和脚本都还在那个专用配置里。

参数：`--dry-run` 只检查不启动 ｜ `--main-profile` 装进平时的浏览器 ｜ `--browser=edge` 指定浏览器 ｜ `--reinstall` 强制重新解包。

## 配置 DeepSeek

打开任意学习通页面 → 面板「**API配置**」标签页：

| 项目     | 填什么                                                                                   |
| -------- | ---------------------------------------------------------------------------------------- |
| API Key  | `sk-` 开头，到 [platform.deepseek.com](https://platform.deepseek.com) 申请，账户需有余额 |
| 模型     | 默认 `deepseek-chat`                                                                     |
| 接口地址 | 默认 `https://api.deepseek.com/v1`                                                       |

点「保存并测试」，绿点显示「接入正常」即可。红灯对照：`401` Key 无效 ｜ `402` 余额不足 ｜ `404` 地址不对 ｜ `429` 限流 ｜ 超时 = 网络不通。

## 设置

| 设置项           | 默认 | 说明                                                 |
| ---------------- | ---- | ---------------------------------------------------- |
| 自动提交（危险） | 关   | 开启后 60 秒倒计时自动提交，期间可点「终止自动提交」 |
| 是否自动下一章节 | 开   | 本页任务点完成后自动进下一章                         |
| 只答题，不做其他 | 关   | 开启后不看视频，只做作业和测验                       |
| 切换、答题间隔   | 3 秒 | 调大更稳但更慢                                       |
| 答案相似度       | 85   | 选择题没被选中时调低                                 |

> 「章节作业自动提交」和「正确率自动提交」两项在 demo 版里已不生效，保留仅为兼容旧配置。

```
.
├── 一键配置.command / .bat      # Mac / Windows 一键配置（双击运行）
├── 使用说明.txt                  # 完整用法（几分钟能看完）
├── 使用前必读.txt                # 用途说明 + 免责声明
└── 配置文件夹/
    ├── xxt-xiaoxin_demo.js       # 用户脚本本体

    └── tampermonkey_stable.crx   # 油猴扩展，供一键配置解包使用
```

一键配置会在 `配置文件夹/` 里生成 `tampermonkey_ext/` 和解包后的浏览器配置 `.browser-profile/`，这两个是生成物，已在 `.gitignore` 里排除。

## 常见问题

| 现象                     | 处理                                              |
| ------------------------ | ------------------------------------------------- |
| 面板不出现               | 脚本没启用，或域名不在 `@match` 里；按 F12 看报错 |
| 题目乱码 / 解析到 0 道题 | 字体映射表没拉到（`forestpolice.org`），刷新重试  |
| 提示要填 API Key         | 到「API配置」页填好并点保存测试                   |
| AI 返回无法解析          | 重试，或把模型换成 `deepseek-chat`                |
| 一直不往下走             | demo 在等你手动提交，属正常行为                   |
| 和其它脚本打架           | 停用其它学习通脚本                                |

脚本依赖 `lib.baomitu.com` 上的 Vue 3 / Element Plus / Pinia / RxJS 和 `forestpolice.org` 的字体反查表，这两个域名访问不了会分别导致面板不出现、题目解析失败。
